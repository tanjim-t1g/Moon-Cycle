## Moon Phase

| Phase | Minecraft Phase | Difficulty | PvP |
|---|---|---|---|
| Large Moon | Waxing Gibbous | Hard | Forced ON |
| Full Moon | Full Moon | Hard | Forced ON |
| Large Moon | Waning Gibbous | Hard | Forced ON |
| Half Moon | Last Quarter | Normal | Player Toggle |
| Small Moon | Waning Crescent | Normal | Player Toggle |
| No Moon | New Moon | Normal | Player Toggle |
| Small Moon | Waxing Crescent | Normal | Player Toggle |
| Half Moon | First Quarter | Normal | Player Toggle |

## Features

- Automatic difficulty and PvP changes based on the moon phase.
- PvP toggling.
- Dimention Isolation.(the plugin only works in Over World)


## Commands

| Command | Description | Permission |
|---|---|---|
| `/moon` | View current phase and rules | `mooncycle.command.status` |
| `/moon preview <phase>` | Preview a specific phase | `mooncycle.command.preview` |
| `/moon reload` | Reload configuration | `mooncycle.command.reload` |
| `/pvp` | Check your PvP status | `mooncycle.command.pvp.status` |
| `/pvp on` / `/pvp off` | Toggle personal PvP | `mooncycle.command.pvp.toggle` |
| `/pvp players` | List online players' PvP states | `mooncycle.command.pvp.status` |
